Pikumi 隐私政策

本政策说明 Pikumi iPhone 无广告版应用及本网站如何处理相关信息。

更新日期：2026年11月17日

1. 开发者与联系方式

Pikumi 的开发者是 Nikita Novikov。如对本政策有疑问，或希望就您的信息提出请求，请使用“联系方式”中的电子邮箱。

2. 照片访问权限与 iCloud

Pikumi 使用您在 iOS 中授予的权限来显示照片、视频及其详细信息，记录整理选择，并在您确认后删除项目。您可以允许访问部分照片或整个图库，也可以随时在“设置”中更改或撤销权限。

照片和视频在您的设备上处理，不会上传给开发者。如果项目存储在 iCloud 中，iOS 可能会从 Apple 下载，以便显示或播放。“iCloud 照片”和设备备份由 Apple 根据您的设置及其隐私政策管理。

3. 设备上保存的数据

Pikumi 会保存整理进度，方便您下次继续。保存的内容包括已整理项目的标识信息、删除队列中项目的详细信息，以及用于撤销操作的选择记录。

应用还会保存已删除项目的数量、估算大小，以及用于判断何时显示 App Store 评分提示的信息。这些数据保存在设备上的应用存储空间中，不会发送给开发者。根据您的设置，Apple 管理的备份可能包含这些数据。

4. 广告、使用分析与账号

此版本不含广告，也不使用第三方应用使用情况分析工具。您无需注册账号，开发者也不为应用运营服务器或云服务。

5. 支持邮件

当您发送邮件寻求帮助时，Nikita Novikov 会收到您的邮箱地址、邮件内容及您主动发送的附件。这些信息用于回复和解决您的问题。问题解决后，开发者会删除相关往来邮件及附件。

支持邮箱使用 Gmail。Google 根据其隐私政策处理邮件，包括邮件保留和备份。开发者从邮箱中删除邮件，并不代表 Google 保存的所有副本都会立即清除。请只提供说明问题所需的信息，避免发送私人照片或密码。

6. 本网站

本网站托管于 GitHub Pages。为向您提供网页，GitHub 会接收您的 IP 地址及网页请求的相关技术信息。具体处理方式见 GitHub 隐私声明。

GitHub 还会出于安全目的记录并保存访客的 IP 地址。

网页不包含分析工具、广告跟踪程序、信息提交表单、外部字体或 JavaScript。切换语言时，不会通过 Cookie 或浏览器存储保存您的选择。

7. 重置进度与删除数据

重置进度会清除整理选择和删除队列，但保留删除统计。删除 Pikumi 应用会移除设备上的应用本地数据，但不会删除您保留的照片和视频，也不会清除 Apple 管理的备份中的数据。

将项目加入队列不会立即删除它，删除需要您另行确认。已删除的项目通常可在“照片”应用的“最近删除”中保留并恢复，期限为 30 天；如果您提前将其永久删除，则无法继续在那里恢复。启用“iCloud 照片”后，删除操作也会同步到使用同一 Apple 账户的其他设备。

8. 您的选择与隐私请求

您可以前往“设置”→“隐私与安全性”→“照片”→ Pikumi，更改或撤销照片访问权限。开发者不持有您的本地图库或整理进度副本，无法为您调取或恢复这些内容。

如需访问、更正或删除您发送到支持邮箱的信息，请通过下方邮箱提出请求。您的权利以适用法律为准，其中可能包括向数据保护机构投诉的权利。

9. 政策更新

如果 Pikumi 的功能或信息处理方式发生变化，本政策也会相应更新。最近一次修订日期显示在页面上方。
